Question 1

Implement the reverse selection sort algorithm that can work on a LinkedList object.

The algorithm should sort a given linked list in descending order. For example:

LinkedList<int> l1{5, -2, 10, 7, 21, 4, 3, 12};
selection_sort(l1); // l1 = {21, 12, 10, 7, 5, 4, 3, -2}

The LinkedList implementation is the same one from lectures and labs; however the get() method, [] overloading and iterators have been purposefully removed from it.

The selection_sort() method is set up so it can access private members of the LinkedList class (head and size).

Answer:(penalty regime: 0 %)
Show solution
template <typename Data>
void selection_sort(LinkedList<Data>& list) {
    for (Node<Data>* i = list.head; i != nullptr; i = i->next) {
        Node<Data>* max = i;                       // node with the largest value so far
        for (Node<Data>* j = i->next; j != nullptr; j = j->next) {
            if (j->data > max->data) {
                max = j;
            }
        }
        swap(i->data, max->data);                  // put it at position i
    }
}

This is selection_sort() from Lab 05 with two changes: indices become node pointers (i and j walk the list), and < becomes >, so each pass picks the largest remaining value. Only the stored values are swapped; the links between nodes stay as they are.

The list is still walked O(n²) times in total, the same as selection sort on an array.

Question 2

Not complete
Marked out of 20.00

Implement a function that counts how many comparisons and swaps have occured during insertion sort.

The insertion_sort_count() function should perform insertion sort on the given array, and count how many comparisons and swaps took place during that process.

In the function, you have the counts array already initialized. The first element of this array should contain the number of comparisons that occured during insertion sort. The second element should contain the number of swaps that occured during insertion sort. In short:

counts[0] = number_of_comparisons
counts[1] = number_of_swaps

The function should return a pointer to the counts array (int*).

Answer:(penalty regime: 0 %)
Show solution
template <typename Data>
int* insertion_sort_count(Data *arr, const int len) {
    int* counts = new int[2]{};

    for (int i = 1; i < len; i++) {
        for (int j = i; j > 0; j--) {
            counts[0]++;                      // arr[j] < arr[j - 1] is evaluated
            if (arr[j] < arr[j - 1]) {
                swap(arr[j], arr[j - 1]);
                counts[1]++;                  // a swap happened
            } else {
                break;
            }
        }
    }
    return counts;
}

Count a comparison every time arr[j] < arr[j - 1] is checked, including the last check that fails and triggers break. Count a swap every time the if is true.

For {5, -1, 23, 8, 17, 4, 2, 6} that gives 21 comparisons and 15 swaps. A sorted array of n elements gives n − 1 comparisons and 0 swaps; a reversed one gives n(n − 1)/2 of each.

Question 3

Not complete
Marked out of 30.00

One of the gap sequences used in Shell sort looks like this:

  • The sequence starts at 1.
  • Every next element is the next prime number that is ≥ 3 times larger than the previous number.

Here is an example: the first element is 1. The next element should be a prime number that is at least 3 times larger than 1, so it will be 3. The next prime number that is at least 3 times larger than 3 is 11, and so on.

Your task is to implement the generate_sequence(n) function that takes in the number of elements to be generated (e.g. if n = 7, generate 7 elements of the sequence). The function returns a pointer to the sequence (int*).

int* sequence = generate_sequence(7);
// Elements: 1, 3, 11, 37, 113, 347, 1049
Answer:(penalty regime: 0 %)
Show solution
bool is_prime(int x) {
    if (x < 2) return false;
    for (int d = 2; d * d <= x; d++) {
        if (x % d == 0) return false;
    }
    return true;
}

int* generate_sequence(const int n) {
    int* sequence = new int[n]{};

    if (n > 0) sequence[0] = 1;
    for (int k = 1; k < n; k++) {
        int candidate = 3 * sequence[k - 1];   // at least 3 times larger
        while (!is_prime(candidate)) {
            candidate++;                        // next prime from there
        }
        sequence[k] = candidate;
    }
    return sequence;
}

Start the search at exactly 3 × previous, because that value itself may be prime (3 × 1 = 3 is). A helper like is_prime() can go above the function in the answer box.

The first 12 elements: 1, 3, 11, 37, 113, 347, 1049, 3163, 9491, 28477, 85439, 256337.

Consider shell_sort() from Lab 05:

template<typename Data>
void ElementarySort::shell_sort(Data *arr, int len) {
   int h = 1;
   while (h < len / 3) {
       h = 3 * h + 1;
   }

   while (h >= 1) {
       for (int i = h; i < len; i++) {
           for (int j = i; j >= h; j -= h) {
               if (arr[j] < arr[j - h]) {
                   swap(arr, j, j - h);
               } else {
                   break;
               }
           }
       }
       h = h / 3;
   }
}

template<typename Data>

   for (int i = 0; i < len; i++) {

           if (arr[j] < arr[min]) {
               min = j;
