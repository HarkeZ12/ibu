FENMS 0121 Data Structures and Algorithms - Week 08: Radix Sort and Counting Sort
=================================================================================

How to open it
1. Extract the ZIP first (right-click > Extract All). Do not open the file
   directly from inside the ZIP.
2. Open the extracted "week08" folder and double-click "reading-08.html".
   It opens in your web browser (Chrome, Edge, Brave, Firefox...).
3. Keep the "images" folder next to "reading-08.html", otherwise the
   figures will not show.

What is inside
- Reading tab: the full study guide for Reading 08 "Radix Sort and Counting
  Sort" (13 sections, 3 figures). Boxes marked "From the lecture" add what
  the lecture slides "08 · Radix Sort & Counting Sort" say about the same
  topic.
- Two live demos in the reading: type your own array and step through radix
  sort pass by pass (the ten buckets, the frequency counts and running
  totals, the joined array), or through counting sort (the count array, the
  running totals and every placement of the backward walk).
- Study notes tab: the most important points of every section on one card:
  the big idea, the usual exam trap and flashcards. Also "Names and
  numbers", "Tracing by hand", "Only on the lecture slides" and the top
  exam traps.
- Quiz tab: 152 questions from the reading material, including trace
  questions (the array after a pass, the number of passes, the digit
  formula, frequency and count arrays, where an element lands). Most trace
  questions have a link that opens their array in the live demo.
- Slides quiz tab: 86 questions only from the lecture slides (the code and
  its line numbers, the traces next to it, the procedure slides, the
  complexity summaries and the run-time tables).
  Answers: by default every question has five options and exactly one
  correct answer, like the quiz in class. Switch to "Several correct
  answers" for harder practice: then two to four options are correct, and a
  question counts only if you tick all of them and nothing else (trace
  questions with a single answer are left out in that mode).
  Choose the levels Easy (common sense), Medium (normal exam questions) and
  Hard (traps and traces), and Practice mode (feedback after every
  question) or Exam mode (results at the end).

No installation is needed. Without internet everything still works; only the
fonts fall back to the standard system fonts.

Online version: https://harkez12.github.io/ibu/

Study features
- "Mark as learned" on each study-notes card is remembered in this browser.
- Saved mistakes persist in this browser across sessions, separately for the
  reading quiz and the slides quiz. Select topics and choose Review saved
  mistakes to practice them. A later correct answer removes that question.
  Changes to a question invalidate its old mistake entry.
- Battery saver in the top bar removes backdrop blur and grain and reduces
  visual effects. Its setting is remembered in this browser.
- Saving needs browser storage; private browsing or clearing browser data can
  remove saved sessions, mistakes and settings.
