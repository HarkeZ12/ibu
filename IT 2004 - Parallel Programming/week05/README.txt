IT 2004 Parallel Programming - Week 05: Parallel Algorithms and Patterns
=======================================================================

How to open it
1. Extract the ZIP first (right-click > Extract All). Do not open the file
   directly from inside the ZIP.
2. Open the extracted "week05" folder and double-click "reading-05.html".
   It opens in your web browser (Chrome, Edge, Brave, Firefox...).
3. Keep the "images" folder next to "reading-05.html", otherwise the
   figures will not show.

What is inside
- Reading tab: the full study guide for Chapter 5 (14 sections, 21 figures).
- Quiz tab: 140 multiple-choice questions with 5 options and exactly one
  correct answer each. Choose Practice mode (feedback after every question)
  or Exam mode (results at the end).

No installation is needed. Without internet everything still works; only the
fonts fall back to the standard system fonts.

Online version: https://harkez12.github.io/ibu/

Study features
- Saved mistakes persist in this browser across sessions. Select topics and
  choose Review saved mistakes to practice them. A later correct answer removes
  that question. Changes to a question invalidate its old mistake entry.
- Battery saver in the top bar removes backdrop blur and grain and reduces
  visual effects. Its setting is remembered in this browser.
- Saving needs browser storage; private browsing or clearing browser data can
  remove saved sessions, mistakes and settings. Moving the file or switching
  browsers/origins may use a separate storage area.

The question bank was reviewed against the downloaded Chapter 5 PDF.
The quiz keeps 140 questions, five options and one correct answer per question.
It includes numerical questions from the chapter (prefix scans, hash keys,
cache-line counts, speedups) as well as conceptual ones.
