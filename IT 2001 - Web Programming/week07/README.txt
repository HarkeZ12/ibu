IT 2001 Web Programming - Week 07: JWT Authentication and Middleware
====================================================================

How to open it
1. Extract the ZIP first (right-click > Extract All). Do not open the file
   directly from inside the ZIP.
2. Open the extracted "week07" folder and double-click "reading-07.html".
   It opens in your web browser (Chrome, Edge, Brave, Firefox...).
3. Keep the "images" folder next to "reading-07.html", otherwise the
   figures will not show.

What is inside
- Reading tab: the full study guide for Reading 07 "JWT Authentication and
  Middleware" (17 sections, 8 figures). Boxes marked "From the lecture" add
  what the lecture slides "Middleware and Authentication, SSO" say about the
  same topic.
- Study notes tab: the most important points of every section on one card:
  the big idea, what to remember, the usual exam trap and flashcards. Also
  "Names, numbers, messages", "Only on the lecture slides", the status code
  game from the lecture and the top exam traps.
- Quiz tab: 131 questions from the reading material.
- Slides quiz tab: 102 questions only from the lecture slides (numbers, RFCs,
  years, exact messages, file names, the CampusEvents examples and the
  status code game).
  Both quizzes have five options per question. Choose "One correct answer"
  or "Several correct answers" (two to four correct, all-or-nothing, like
  the LMS), the levels Easy (common sense), Medium (normal exam questions)
  and Hard (traps and subtle details), and Practice mode (feedback after
  every question) or Exam mode (results at the end).

No installation is needed. Without internet everything still works; only the
fonts fall back to the standard system fonts.

Online version: https://harkez12.github.io/ibu/

Study features
- "Mark as learned" on each study-notes card is remembered in this browser.
- Saved mistakes persist in this browser across sessions, separately for the
  reading quiz and the slides quiz. Select topics and choose Review saved
  mistakes to practice them. A later correct answer removes that question.
  Changes to a question invalidate its old mistake entry.
- Battery saver in the top bar removes backdrop blur and grain and reduces
  visual effects. Its setting is remembered in this browser.
- Saving needs browser storage; private browsing or clearing browser data can
  remove saved sessions, mistakes and settings.

Source: IT 2001 Web Programming, Reading 07 "JWT Authentication and
Middleware" and the lecture slides "Middleware and Authentication, SSO",
International Burch University, 2026/2027.
