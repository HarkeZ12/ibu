In the assignment you protect your REST API: you get files with missing code or write them from scratch. Every task is one file of the lecture project (CampusEvents, week 7). Each task has two modes:
  • Whole file: the starter file with // TODO comments – write all of the missing code.
  • Missing lines: one to three lines of the solution are replaced with // TODO: missing line; New gaps removes different ones.
  • Exam (top right) hides the hints and the solutions – only the TODO comments stay, like in the assignment.
  • Check puts your file into the CampusEvents backend (FlightPHP 3.19, firebase/php-jwt 7); every other file is the original solution. Then it sends real requests and reads logs/info.log and logs/error.log.

Database: SQLite instead of MySQL, with the users ema@campusevents.ba / Student123! (student, id 2) and admin@campusevents.ba / Admin123! (admin, id 1). It is fresh for every check.
