IT 2001 Web Programming - Week 05: Presentation Layer
=======================================================

How to open it
1. Extract the ZIP first (right-click > Extract All). Do not open the file
   directly from inside the ZIP.
2. Open the extracted "week05" folder and double-click "reading-05.html".
   It opens in your web browser (Chrome, Edge, Brave, Firefox...).
3. Keep the "images" folder next to "reading-05.html", otherwise the
   figures will not show.

What is inside
- Reading tab: the full study guide for Reading 05 (16 sections, 2 figures),
  including the Check Yourself answers and the glossary.
- Quiz tab: 135 questions with 5 options; every question has 2, 3 or 4
  correct answers (pick all of them, no wrong one). Choose
  Practice mode (feedback after every question)
  or Exam mode (results at the end).

No installation is needed. Without internet everything still works; only the
fonts fall back to the standard system fonts.

Online version: https://harkez12.github.io/ibu/

Study features
- Saved mistakes persist in this browser across sessions. Select topics and
  choose Review saved mistakes to practice them. A later correct answer removes
  that question.
- Battery saver in the top bar removes backdrop blur and grain and reduces
  visual effects. Its setting is remembered in this browser.
- Saving needs browser storage; private browsing or clearing browser data can
  remove saved sessions, mistakes and settings.

Lab 05 trainer (folder "lab05-trainer")
- Practise the Lab 05 tasks: the services registration, the error handler,
  notFound and the routes for categories, events and announcements, plus two
  extra files to write from memory. Press Check and your code runs in real
  PHP 8.4 inside the browser (FlightPHP, the original services and DAOs, an
  SQLite copy of campusevents.sql); every request is compared with the
  expected answer, like php rest/routes/test_tasks.php.
- Easiest: open it online at https://harkez12.github.io/ibu/
- From the ZIP it needs a small local web server (opening index.html directly
  does not work): on Windows double-click "Start trainer.bat", on Linux/macOS
  run "bash start.sh" in the lab05-trainer folder. Keep that window open while
  you practise.

Source: IT 2001 Web Programming, Reading 05 "Presentation Layer",
