IT 2002 System Analysis and Design - Week 05: Use Cases and Use Case Diagrams
============================================================================

How to open it
1. Extract the ZIP first (right-click > Extract All). Do not open the file
   directly from inside the ZIP.
2. Open the extracted "week05" folder and double-click "reading-05.html".
   It opens in your web browser (Chrome, Edge, Brave, Firefox...).
3. Keep the "images" folder next to "reading-05.html", otherwise the
   diagrams will not show.

What is inside
- Reading tab: the full study guide for Reading 05 (10 chapters, 16 figures).
- Quiz tab: multiple-choice quiz with 5 options per question. Most questions
  have several correct answers ("Select one or more"). Choose Practice mode
  (feedback after every question) or Exam mode (results at the end).

No installation is needed. Without internet everything still works; only the
fonts fall back to the standard system fonts.
